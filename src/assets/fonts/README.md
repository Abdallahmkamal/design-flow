# Vodafone VF webfont

`VodafoneVF_Wght_W.woff2` is the approved Vodafone VF v4.000 variable webfont
supplied for Design Flow on 2026-07-20.

- Family: `Vodafone VF`
- Format: WOFF2, TrueType outlines
- Axis: `wght`
- Supported range: 200 (ExtraLight) through 900 (Black)
- Default instance: Regular
- Supported scripts: Latin, Greek, Cyrillic, and Arabic
- SHA-256:
  `54ab08e97c86cce1689d645e5b80ed0c4c06e30f5e04a14066afb0403ce612ed`

The accompanying Vodafone v4.000 release notes identify the font for web use,
permit editable embedding and subsetting, and state that WOFF2 is the delivered
variable-webfont format. This repository consumes the supplied file directly
and does not synthesize intermediate weights.

Do not replace, redistribute, subset, or convert the asset without confirming
the applicable Vodafone brand and font-licensing approval.
